# MK Certiva Solutions — Static Website

This package contains the editable website files converted from the provided PDF format and its red annotations. It has no Node.js backend.

## Files
- `index.html` — Home
- `about.html` — About Us, Mission, Vision, Values
- `services.html` — Services, 20 standards, certification process and feedback process
- `industries.html` — Industries served
- `contact.html` — Contact and feedback forms that open a prefilled WhatsApp message, plus FAQs
- `styles.css` — Website design and responsive styles
- `assets/` — Logo, WhatsApp icon, map and favicon

## Edit
Open the HTML files in VS Code or any text editor. Keep `assets/` and `styles.css` beside the HTML files.

## Preview
Double-click `index.html` to preview. When visitors submit either form on the Contact page, WhatsApp opens with their details prefilled for sending to MK Certiva Solutions at `0312-4036814`. The website does not store submissions itself.
